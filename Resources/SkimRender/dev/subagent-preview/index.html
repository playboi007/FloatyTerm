What changes
  • Agents are avatars at the top right. The ring says the state: it turns while the agent works, yellow when it needs you, green when done.
  • Hover the stack: it spreads. Hover an avatar: it grows into a card with the task, the live step, the last steps and the numbers.
  • Click an avatar: its conversation opens in the column. The composer says “To Explore”: you talk to that agent, as in the TUI.
  • In Main, an Agent call is one line with the same avatar.
  • Keys: ⌥1…9 open an agent, Esc back to Main, ⌃B background, ⌃X stop.
